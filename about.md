# About This Project

## What's the Problem?

If you've ever tried to hire someone or work as a freelancer/contractor, you know the pain:

- Text messages scattered all over WhatsApp
- Email threads you can't find
- Spreadsheets tracking who quoted what
- No way to know if someone's actually reliable
- Negotiating prices over 10 different platforms

It's messy. It's chaotic. There has to be a better way.

## So I Built This

**Vendor Platform** is basically Airbnb but for contractors and service providers. Everything happens in one place:
- Post a job and contractors bid on it
- Chat with them directly (no more jumping between apps)
- See their past work and what people say about them
- Track who's working on what
- Get paid safely through milestones
- Leave honest reviews

Simple. Clean. Actually works.

## Who Made This?

Started by **Virat Paudel** as an MVP (minimum viable product). The idea was to test if people actually wanted this instead of building a million features nobody needs.

## What's Inside?

**Backend:** Express + Node.js  
**Frontend:** React + Vite (fast as hell)  
**Database:** SQLite (started simple, can scale)  
**Design:** Dark theme with that modern glassmorphism look  

The code is pretty straightforward - no crazy overengineering. Built to actually work and be easy to modify.

## What Can You Do?

### If You're a Vendor/Contractor:
- Show off your portfolio
- Add certifications to prove you know your stuff
- Get hired for projects
- Track milestones
- Get paid when work is done
- Build your reputation

### If You're Hiring:
- Post exactly what you need
- See qualified people apply with their rates
- Chat with them to make sure they're not sketchy
- Break the project into milestones (pay as you go)
- Make sure the work is done before paying final amount
- Leave a review so others know how to work with them

## Why This Matters

A lot of platforms treat contractors like second-class citizens or charge ridiculous fees. This is different. It's built for real people doing real work.
