# Features

## Core Features

### Authentication & Profiles
- ✅ Secure user registration with bcrypt password hashing
- ✅ Login with email and password
- ✅ Separate profiles for vendors and project posters
- ✅ User information storage (name, email, phone, location)

### Project Management
- ✅ Post detailed projects with requirements
- ✅ Set budget, deadline, and location
- ✅ Specify experience level needed
- ✅ List required skills
- ✅ Define project scope
- ✅ Choose payment method and contract type
- ✅ Track project status
- ✅ View all active projects

### Vendor Features
- ✅ Complete vendor profile
- ✅ Showcase portfolio items with descriptions and links
- ✅ Add professional certifications
- ✅ Track experience and skills
- ✅ Set pricing and availability
- ✅ View assigned projects
- ✅ Browse and bid on projects
- ✅ Accept/reject quotations
- ✅ Track work milestones
- ✅ Receive milestone-based payments

### Quotations & Bidding
- ✅ Submit quotations for projects
- ✅ Detailed proposal descriptions
- ✅ Quotation status tracking (pending/accepted/rejected)
- ✅ View competing quotations
- ✅ Accept best quotation
- ✅ Direct communication with vendors

### Communication
- ✅ Real-time in-app messaging
- ✅ Chat per project
- ✅ View message history
- ✅ Direct vendor-contractor communication
- ✅ No need to switch platforms

### Project Milestones
- ✅ Break projects into phases

- ✅ Track completion status

### Contract Management
- ✅ Automatic contract generation

- ✅ Multiple payment methods

- ✅ Rate vendors after project completion
